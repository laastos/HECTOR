## Overview

HECTOR addresses the challenge of identifying protein scaffolds with surface patches complementary to a target epitope. The key innovation is a **fingerprint-based approach** that:

1. Compresses 3D surface patches into 2D "maps" (fingerprints)
2. Enables trivial inversion for complementarity matching
3. Achieves rotation-invariance through cylindrical projection
4. Allows ultra-fast comparison (sub-microsecond per evaluation)

## Surface Fingerprinting

### Step 1: Surface Mesh Generation

HECTOR begins with a triangulated molecular surface generated by EDTSurf:

```
EDTSurf -i protein.pdb -o protein.ply -s 3
```

The PLY file contains:
- **Vertices**: 3D coordinates (x, y, z) of surface points
- **Faces**: Triangle indices defining the mesh topology
- **Normals**: Surface normal vectors at each vertex

### Step 2: Dot Surface Extraction

The triangulated mesh is converted to a dot-surface representation:

1. **Triangle Centers**: Compute center of each triangular face
2. **Surface Normals**: Calculate outward-pointing unit normal for each triangle
3. **Dot Density**: Average of ~20 dots per square Angstrom

```python
# Triangle centers as representative vertices
tris_cntrs = np.average(ply_vrtx_arr[ply_fc_arr], axis=1)

# Calculate triangle normals via cross product
tris_nrmls = np.cross(tris[::,1] - tris[::,0], tris[::,2] - tris[::,0])

# Normalize to unit vectors
tris_unt_nrmls = normalise(tris_nrmls)
```

### Step 3: Surface Inflation (Optional)

An optional inflation step accounts for surface uncertainty:

```python
# Inflate surface by infltn_fctr Angstroms along normal direction
tris_cntrs = tris_cntrs + infltn_fctr * tris_unt_nrmls
```

**Recommended value**: 0.5 Angstrom

## Spin Image Generation

The core fingerprinting function uses **spin images**, a well-established shape descriptor that maps 3D surface patches to 2D representations.

### Mathematical Foundation

For each surface point with:
- **Position vector** `p` (patch center)
- **Unit normal** `n` (local z-axis)

Every neighboring surface point `x` is projected using the **spin mapping** S_O:

```
S_O: R^3 -> R^2
S_O(x) -> (alpha, beta)

where:
  alpha = sqrt(||x-p||^2 - (n.(x-p))^2)  # radial distance
  beta = n.(x-p)                          # axial distance
```

### Cylindrical Basis Projection

Each surface patch F_i is defined as points within a cylindrical region:

```
F_i = {s_c | s_c in S_c,
       ||(s_c - s_ci) x n_i|| / ||n_i|| < R_max,   # radial constraint
       |(s_c - s_ci) . n_i| < H_max/2}             # axial constraint
```

**Parameters:**
- `R_max`: Maximum radial distance (support distance alpha)
- `H_max`: Maximum axial height (support distance beta)

### Vectorized Implementation

```python
def spn_map_srfc(srfc_vrtx_arr, srfc_nrml_arr,
                 spprt_dstnc_x, spprt_dstnc_y,
                 bin_sz, dot_skp_frq, dot_map_frq):
    """
    Generate spin image fingerprints for surface patches.

    For each reference vertex (vrtx) with normal (n):
    1. Compute x-p for all neighboring vertices
    2. Calculate beta = n.(x-p) (axial projection)
    3. Filter by |beta| <= half_support_distance
    4. Calculate alpha = sqrt(||x-p||^2 - beta^2) (radial distance)
    5. Filter by alpha <= support_distance_x
    6. Bin into 2D histogram
    """
    for vrtx, n in zip(srfc_vrtx_arr[::dot_skp_frq,:],
                       srfc_nrml_arr[::dot_skp_frq,:]):
        # Vector from reference to all vertices
        xp_arr = srfc_vrtx_arr[::dot_map_frq,:] - vrtx

        # Axial projection (beta)
        beta_arr = np.dot(n, xp_arr.T)

        # Filter by axial distance
        lmt_idx_arr = np.where(np.abs(beta_arr) <= half_spprt_dstnc)[0]

        # Calculate radial distance (alpha)
        alpha_arr = np.sqrt((lmt_xp_norm_arr**2) - (lmt_beta_arr**2))

        # Bin into 2D map
        i_arr = ((half_spprt_dstnc - beta)/bin_sz).astype(int)
        j_arr = (alpha/bin_sz).astype(int)
```

### Dimensionality Reduction

The 3D cylindrical projection is collapsed along the angular dimension (theta) to produce a 2D map:

```
T_r: g(r, theta, l) -> h(r, l) := integral of g(r, theta, l) d_theta
```

This integration:
1. **Reduces dimensionality**: 3D -> 2D
2. **Achieves rotation invariance**: Map independent of rotation around normal
3. **Produces fixed-size output**: Constant map dimensions regardless of patch size

## Fingerprint Invertibility

A key property of HECTOR fingerprints is **invertibility**: a query fingerprint can be trivially inverted to describe its ideal complementary surface.

### Forward vs. Inverse Mapping

```python
sign = {"lgnd": -1, "rcpt": 1}

# Forward mapping (receptor/subject): k = +1
# Inverse mapping (ligand/query): k = -1

T_p: f(x, y, z) -> g(r, theta, l) := [sqrt(x^2 + y^2),
                                       1/tan(y/x),
                                       k * z]        # k controls direction
```

### Inversion Operation

To find complementary surfaces:

```python
def inv_maps(lgnd_maps):
    """Invert ligand maps by flipping along the axial dimension."""
    lgnd_inv_maps_lst = []
    for i in range(lgnd_maps.shape[0]):
        matrix = lgnd_maps[i]
        inverted_matrix = matrix[::-1, :]  # Flip rows
        lgnd_inv_maps_lst.append(inverted_matrix)
    return np.array(lgnd_inv_maps_lst)
```

## R-Factor Calculation

The **R-factor** quantifies dissimilarity between two fingerprints. Lower values indicate higher complementarity.

### HECTOR v0.1 Formula

Original formulation based on normalized differences:

```
R = sum(|F/sum(F) - I/sum(I)|)
```

where:
- `F`: Forward-mapped subject fingerprint
- `I`: Inverse-mapped query fingerprint

### HECTOR v0.2 Formula (Improved)

Enhanced formulation emphasizing overlap:

```
R = sum((2 * F * I + C) / (F^2 + I^2 + C)) / N
```

where:
- `N`: Number of elements in the matrices
- `C = 0.0001`: Numerical stability constant

### SSIM-Based Comparison

The implementation uses a modified Structural Similarity Index (SSIM):

```cython
cpdef ssim(np.ndarray[DTYPE_t, ndim=2] im1,
           np.ndarray[DTYPE_t, ndim=2] im2,
           float data_range=1,
           float K1=0.01):

    C1 = (K1 * data_range) ** 2

    for i in range(dim1):
        for j in range(dim2):
            S[i,j] = ((2 * im1[i,j] * im2[i,j]) + C1) /
                     (im1[i,j]**2 + im2[i,j]**2 + C1)

    return S.mean()
```

### R-Factor Interpretation

| R-factor | Interpretation |
|----------|----------------|
| -1.0 | Perfect complementarity |
| -0.8 | High complementarity (recommended cutoff) |
| -0.5 | Moderate complementarity |
| 0.0 | No correlation |
| +1.0 | Perfect similarity (not complementary) |

## Database Search Strategy

HECTOR uses a **two-vs-all search strategy** with multiple query patches.

### Query Selection

Select 2-3 surface patches at the target epitope:
- Minimum 10 Angstrom between patch centers
- Avoid glycosylation sites
- Choose patches representative of the binding interface

### Search Algorithm

1. **One-vs-All for Query 1**: Find top N% subjects with lowest R-factor
2. **One-vs-All for Query 2**: Find top N% subjects with lowest R-factor
3. **Distance Filtering**: Retain pairs where inter-patch distance matches query
4. **R-factor Filtering**: Keep pairs with average R-factor below cutoff
5. **RMSD Ranking**: Align and rank by structural similarity

```python
# Step 1 & 2: Select top 5% of subject maps for each query
n_top_hits = int(r_ij_0_sort.shape[0] * top_pct / 100)
top_qry_0 = r_ij_0_sort[:n_top_hits, :]
top_qry_1 = r_ij_1_sort[:n_top_hits, :]

# Step 3: Filter by inter-patch distance
dist_range = [(intr_qry_dist - dist_tol), (intr_qry_dist + dist_tol)]
dist_filt = (dist_ij[:, 0] >= dist_range[0]) & (dist_ij[:, 0] <= dist_range[-1])

# Step 4: Filter by R-factor
filt_map_pairs_rf = filt_map_pairs_rf[filt_map_pairs_rf[:, 3] <= rf_cutoff]
```

## Docking and Filtering

### Kabsch Alignment

The Kabsch algorithm aligns subject scaffolds to query positions:

```python
def kabsch_v2(P, Q):
    """
    Align point sets P and Q using SVD.

    Returns:
    - Aligned coordinates
    - Rotation matrix
    - Translation vectors
    - RMSD
    """
    # Center both point sets
    centroid_P = np.mean(P, axis=0)
    centroid_Q = np.mean(Q, axis=0)

    P_centered = P - centroid_P
    Q_centered = Q - centroid_Q

    # Compute covariance and SVD
    H = np.dot(P_centered.T, Q_centered)
    U, S, Vt = np.linalg.svd(H)

    # Rotation matrix
    rotation_matrix = np.dot(U, Vt)

    # RMSD calculation
    P_aligned = np.dot(P_centered, rotation_matrix)
    rmsd = np.sqrt(np.mean(np.linalg.norm(Q_centered - P_aligned, axis=1)**2))

    return P_aligned, rotation_matrix, translation, rmsd
```

### Four-Point Anchoring

Alignment uses 4 anchor points:
- 2 patch centers (from both query patches)
- 2 normal endpoints (patch center + normal vector)

### Filtering Criteria

| Criterion | Cutoff | Description |
|-----------|--------|-------------|
| RMSD | <= 0.5 A | Alignment quality |
| Surface Overlap | <= 125,000 voxels | Steric clashes |
| Interface Residues | >= 25 | Binding site coverage |

### Overlap Calculation

Surface overlap is computed using voxelized solvation kernels:

```python
def calc_ovrlp(qry_atms_lst, sbj_atms_lst, slv_rsltn, slv_n_vxls, slv_dict, spprt_dstnc):
    """
    Calculate steric overlap between query and subject structures.

    Uses tensorized projections of solvation kernels to quantify
    volume intersection at interface residues.
    """
    # Project atoms onto voxel grid
    qry_msk_mat = prjct_msk_solv(qry_atms, slv_rsltn, slv_n_vxls, slv_dict, spprt_dstnc)
    sbj_msk_mat = prjct_msk_solv(sbj_atms, slv_rsltn, slv_n_vxls, slv_dict, spprt_dstnc)

    # Count overlapping voxels
    ovrlp = np.sum((qry_msk_mat - 1) * (sbj_msk_mat - 1))

    return ovrlp, n_interface_residues
```

## Algorithm Parameters

### HECTOR v0.1 Parameters

| Parameter | Value | Description |
|-----------|-------|-------------|
| Mapping frequency | 1:40 | Map every 40th surface dot |
| Mapping density | 1:8 | Use every 8th dot for projection |
| Radial span | [0, 12] A | Cylindrical basis radius |
| Axial span | [-6, 6] A | Cylindrical basis height |
| Map resolution | 0.4 A | Bin size |
| Map dimensions | 30 x 30 | Output matrix size |
| Interpolation | Bilinear | Applied to smooth maps |

### HECTOR v0.2 Parameters (Improved)

| Parameter | Value | Description |
|-----------|-------|-------------|
| Mapping frequency | 1:5 | Map every 5th surface dot |
| Mapping density | 1:1 | Use all dots (maximum density) |
| Radial span | [0, 10] A | Cylindrical basis radius |
| Axial span | [-10, 10] A | Cylindrical basis height |
| Map resolution | 0.2 A | Bin size (higher resolution) |
| Map dimensions | 50 x 100 | Output matrix size |
| Radial fading | 40 bins, slope 0.3 | Sigmoid edge weighting |
| Surface inflation | 0.5 A | Uncertainty compensation |
| Interpolation | None | Eliminated (sufficient density) |

### Recommended Cutoffs

| Filter | Value | Notes |
|--------|-------|-------|
| R-factor | <= -0.82 | High complementarity |
| Distance tolerance | +/- 0.01 A | Inter-patch distance |
| RMSD | <= 0.5 A | Alignment quality |
| Overlap | <= 125,000 voxels | Avoid clashes |
| Interface residues | >= 25 | Sufficient contact |

## Performance Characteristics

### Computational Complexity

| Stage | Complexity | Time (typical) |
|-------|------------|----------------|
| Surface mapping | O(N * M) | 7 min/protein on CPU |
| Per-map generation | O(1) | 15 ms/patch |
| R-factor evaluation | O(1) | 20 us/pair on CPU, <1 us on GPU |
| Database search | O(Q * D) | Minutes for typical databases |

where:
- N = number of surface dots
- M = number of maps
- Q = number of query map pairs
- D = database size

### GPU Acceleration

R-factor calculations can be vectorized on GPU using ArrayFire:
- **CPU**: ~20 microseconds per comparison
- **GPU**: <1 microsecond per comparison
